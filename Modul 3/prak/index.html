Form HTML

Latihan dan tugas praktikum bab Form HTML.

Latihan Praktikum

Kode latihan dari modul (sudah diperbaiki dan dirapikan, lihat Tugas a dan b).

  • formulir.html

Tugas Praktikum

  • a. Perbaiki source code praktikum. Perbaikan pada formulir.html:
    • Spasi pada action=" formulir.html" dihapus.
    • Spasi di akhir <title> dihapus.
    • <option>Bandung</option> diberi atribut value.
    • Atribut value="Nama Kamu" diganti placeholder, dan value pada checkbox ditambahkan.
    • Teks di dalam <textarea> memakai ejaan baku, dan nama komentar diperbaiki.
    • Ditambahkan lang, meta charset, dan tag <label> dengan id.
  • b. Susunlah source code serapi mungkin. Indentasi konsisten, tiap kolom dibungkus <p> (bukan <br />), dan tag ditulis seragam.
  • c. Formulir_Perpuskotamadiun.html (pendaftaran anggota Perpustakaan Kota Madiun)
  • d. Formulir_kliniksehat.html (pendaftaran pasien Klinik Sehat)

Tag yang dipakai: form, input (text, password, checkbox, radio, submit), textarea, select, dan label.
